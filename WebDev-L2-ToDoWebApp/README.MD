# WebDev-L2-ToDoWebApp

## Project Overview

This project is a **To-Do Web App** developed as part of the **Oasis Infobyte Internship Program (OIBSIP)** – Web Development Level 2, Task 3.

The application allows users to create and manage their daily tasks through a simple, interactive, and user-friendly web interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and user-friendly interface
* Responsive design
* Interactive task management
* Organized task list

## How to Run

1. Download or clone the repository.
2. Open the `WebDev-L2-ToDoWebApp` folder.
3. Open `index.html` in any modern web browser.
4. Add, complete, or delete tasks using the application.
