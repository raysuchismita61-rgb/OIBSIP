# WebDev-L2-LoginAuthenticationSystem

## Project Overview

This project is a **Login Authentication System** developed as part of the **Oasis Infobyte Internship Program (OIBSIP)** – Web Development Level 2, Task 4.

The system provides a simple user authentication interface that allows users to register, log in, and access the application through a user-friendly web interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* User registration interface
* User login interface
* Basic authentication functionality
* Form validation
* Password input field
* User-friendly interface
* Responsive design
* Logout functionality

## Project Structure

```text
WebDev-L2-LoginAuthenticationSystem/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the `WebDev-L2-LoginAuthenticationSystem` folder.
3. Open `index.html` in any modern web browser.
4. Register or log in using the available authentication forms.
